# Lab 4b: Client-Side Scripting (JSON and jQuery)

Course: BIC21203 – Web Development

## 1. Project Description

This project demonstrates web page development using JSON, modern JavaScript, and jQuery. It consists of three activities involving JSON data creation, retrieving and displaying JSON data, and DOM manipulation using jQuery.

## 2. Project Files

- `books.json`: Stores information about two books in JSON format 
- `books.html`: Uses JavaScript fetch() to retrieve and display book information 
- `jquery-dom.html`: Demonstrates DOM manipulation and event handling using jQuery 

## 3. Technologies Used

- HTML5
- CSS3
- JavaScript
- JSON
- jQuery 4.0.0

## 4. How to Run the Project

1. Download or clone this repository.
2. Open the project folder using Visual Studio Code.
3. Install the Live Server extension if it is not already installed.
4. Right-click `books.html` and select Open with Live Server to view the JSON data.
5. Right-click `jquery-dom.html` and select Open with Live Server to test the jQuery operations.
6. Ensure an internet connection is available to load the jQuery CDN.

## 5. Learning Outcomes

- Create and structure valid JSON data.
- Retrieve and display JSON data using the JavaScript fetch() API.
- Handle JSON parsing and request errors.
- Perform DOM manipulation and event handling using jQuery.
- Understand the differences between native JavaScript and jQuery.
